## 营养与膳食

### 日常吃什么

- [中国居民膳食指南（2022）核心推荐](https://wjw.fj.gov.cn/ztzl/jkjy/jkzgxd/202206/t20220615_5930367.htm) — 中国营养学会编写、福建省卫健委转载的公开要点，适合了解中国居民的一般膳食建议。
- [中国居民平衡膳食宝塔与餐盘（2022）](https://wjw.tongliao.gov.cn/xwzx/jktl/202207/t20220715_830329.html) — 通辽市卫健委转载的图示和使用说明，适合按食物类别安排一日三餐。
- [健康饮食餐盘](https://nutritionsource.hsph.harvard.edu/healthy-eating-plate/translations/chinese-simplified/) — 哈佛大学公共卫生学院的简体中文餐盘图解，方便快速了解一餐的搭配。
- [世卫组织健康饮食指南](https://www.who.int/zh/news-room/fact-sheets/detail/healthy-diet) — 中文科普，涵盖碳水化合物、脂肪、蛋白质、盐和游离糖。
- [如何看懂营养成分表](https://www.fda.gov/food/nutrition-facts-label/how-understand-and-use-nutrition-facts-label) — 美国 FDA 用样例讲解每份含量和每日参考百分比，适用于美国食品标签（英文）。

### 按年龄查指南

- [3 岁以下婴幼儿喂养和营养指南](https://dghb.dg.gov.cn/zsjg/dzsjbyfkzzx/ztzl/yyeyyzl/yyeyyzl/post_3962200.html) — 东莞市疾控中心发布的分龄参考，适合查阅母乳喂养和辅食添加。
- [中国学龄儿童膳食指南（2022）核心推荐](https://dghb.dg.gov.cn/zsjg/dzsjbyfkzzx/jkzt/xxws/content/post_4201245.html) — 围绕正餐、零食、饮水和食育的公开要点，适合家长和学校参考。
- [高龄老年人膳食指南](https://www.yantai.gov.cn/art/2023/10/25/art_93895_3152754.html) — 烟台市政府网站发布的要点，面向 80 岁以上老年人和照护者。

### 体重管理与慢病饮食

> 涉及慢病、用药或特殊营养需求时，请和医生或注册营养师一起制定个人饮食方案。

- [成人肥胖食养指南（2024 年版）](https://www.nhc.gov.cn/cms-search/downFiles/cbd48e38de3d4b8bb3e2093c9fbd43a5.pdf) — 国家卫健委发布，含分地区、分季节的食谱示例，主要面向成人肥胖人群及相关专业人员（PDF）。
- [2023 年食养指南要点](https://dghb.dg.gov.cn/zsjg/dzsjbyfkzzx/jkzt/jkxj/qmyyz/content/post_4012231.html) — 东莞市疾控中心整理的成人高血压、高脂血症、糖尿病和儿童青少年生长迟缓食养要点。
- [成人脑卒中、骨质疏松症和肌少症食养指南（2026 年版）](https://www.ghx.gov.cn/ghx/zfxxgk/fdzdgknr/zdmsxx/ylws/art/2026/art_dfe4eee281da4a3ebd429c4608e65b38.html?xxgkFlg=xxgk) — 广河县政府转载的国家卫健委发布页，附三份指南全文和配套问答。

### 系统学习与查询

- [Human Nutrition: 2020 Edition](https://pressbooks.oer.hawaii.edu/humannutrition2/) — 夏威夷大学开放教材，覆盖营养素、消化吸收、能量代谢和不同生命阶段的营养（英文全文）。
- [食物营养成分查询平台](https://nlc.chinanutri.cn/fq/) — 中国疾控中心营养与健康所的在线查询，可按食物名称查看能量和营养素数据。

## 健康与长寿

- [中国公民健康素养——基本知识与技能释义（2024 年版）](https://www.gov.cn/lianbo/bumen/202405/P020240530783730074981.pdf) — 国家卫健委编写的综合手册，涵盖就医、口腔卫生、日常防护和急救（PDF）。
- [睡眠健康核心信息及释义](https://www.echeng.gov.cn/ecqxxgk/bmptlj/qzbm/ecqwjj/fdzdgk/hygq/202504/t20250430_701067.html) — 鄂城区卫健局转载的全国爱卫办资料，介绍睡眠环境、规律作息和就医时机。
- [世卫组织身体活动简明指南](https://www.who.int/zh/news-room/fact-sheets/detail/physical-activity/) — 按人群概述身体活动建议和久坐相关知识，可与英文完整版配合阅读。
- [压力之下，择要事为之](https://iris.who.int/bitstream/handle/10665/331901/9789240003910-chi.pdf) — 世界卫生组织的中文图解压力管理手册，附可自行练习的方法。
- [身体活动和久坐行为指南](https://www.who.int/publications/i/item/9789240015128) — 世界卫生组织按年龄和人群编写的公共卫生指南（英文）。
- [程序员延寿指南](https://github.com/geekan/HowToLiveLonger) — 健康与长寿相关研究。

## 日常生活

- [程序员做饭指南](https://github.com/Anduin2017/HowToCook) — 家常菜与烹饪步骤。
- [食品安全五大要点手册](https://www.who.int/publications/i/item/9789241594639) — 世界卫生组织的食品安全手册，覆盖清洁、生熟分开、加热和储存等厨房场景。
- [如何处理剩余食物](https://www.cfs.gov.hk/sc_chi/consumer_zone/safefood_all/five_keys_apply_leftovers.html) — 香港食物安全中心简体中文指南，讲解家庭剩菜的保存和复热。
- [租房实地看房指南](https://zjw.beijing.gov.cn/bjjs/fwzlfw84/wsczr/cjwd44/744029807/index.shtml) — 北京市住建委整理的看房要点，涉及出租渠道、房屋情况及配套设施。
- [公民生态环境行为规范十条](https://www.mee.gov.cn/home/ztbd/2020/gmst/wenjian/202306/t20230615_1033831.shtml) — 生态环境部发布的日常行动指南，涉及节能、绿色消费和垃圾分类。

## 安全与防骗

- [人间防骗指南](https://github.com/QERSSD/HowToAvoidScams) — 常见骗局与风险识别。
- [Security in a Box 数字安全指南](https://securityinabox.org/zh/) — Front Line Defenders 项目的中文数字安全手册。
- [电子前哨基金会数字安全自卫指南](https://ssd.eff.org/zh-hans) — 按使用场景查找账号、设备和通信隐私的操作指南，部分条目为英文。
- [FTC 防诈骗指南](https://consumer.ftc.gov/scams) — 按冒充身份、网购、招聘等场景查找骗局识别材料，举报渠道适用于美国（英文）。
- [家庭应急物资清单](https://www.redcross.org/get-help/how-to-prepare-for-emergencies/survival-kit-supplies.html) — 美国红十字会的备灾清单，适合盘点饮水、照明和重要文件等家庭应急用品（英文）。
- [防范电信网络诈骗宣传手册（2025 版）](https://fr.china-embassy.gov.cn/zgzfg/zgsg/lsqwc/202509/P020250912596090049380.pdf) — 公安部刑侦局编写、驻法国使馆转载的图文手册，包含常见电诈案例和识别要点（PDF）。
- [全国基础版家庭应急物资储备建议清单](https://www.mem.gov.cn/kp/shaq/202011/t20201129_372149.shtml) — 应急管理部发布的中国家庭应急物资清单，按饮食、照明、防护等需求整理。
- [家庭应急计划](https://www.mem.gov.cn/kp/shaq/201904/t20190401_365926.shtml) — 应急管理部发布的指南，帮助家庭约定疏散路线、联络方式和集合安排。
- [社区消防安全知识常识](https://www.mem.gov.cn/kp/shaq/201904/t20190401_366005.shtml) — 应急管理部发布的消防科普，涵盖社区和居家防火、报警和逃生。
