# Awesome Life Guides · 人生实用指南合集

> 把学校没教、生活却需要的知识，整理成一份持续更新的人生说明书索引。

精选免费公开阅读的指南、手册与电子书，优先中文、实用性和原始来源。

按眼下的问题查找资源。刚上大学可以从[大学生存手册](https://github.com/SurviveSJTU/SurviveSJTUManual/releases)读起，想整理账单可以从[预算工作表](https://www.consumerfinance.gov/consumer-tools/educator-tools/your-money-your-goals/toolkit/)着手，遇到消费纠纷可以查看[投诉提交步骤](https://www.beijing.gov.cn/fuwu/bmfw/bmjy/202504/t20250409_4060597.html)。

## 人生与成长
- [高性价比人生指南](https://github.com/eternity4719/HowToLiveBetter) — 人生决策与生活经验。
- [清华大学计算机系课程攻略](https://github.com/PKUanonym/REKCARC-TSC-UHT) — 清华大学计算机课程学习资源（偏技术学习）。
- [CS 自学指南](https://github.com/PKUFlyingPig/cs-self-learning) — 计算机科学自学路线与课程。
- [上海交通大学生存手册](https://github.com/SurviveSJTU/SurviveSJTUManual/releases) — 从学生视角介绍选课、学习、实习和校园生活，校务信息以学校最新发布为准。
- [College Success](https://openstax.org/books/college-success/pages/1-introduction) — OpenStax 免费教材，涵盖时间管理、学习策略和大学适应（英文）。
- [沉思录](https://standardebooks.org/ebooks/marcus-aurelius/meditations/george-long) — 马可·奥勒留关于自律、逆境和责任的笔记，适合按篇阅读（英文公版译本）。

## 人际关系
- [人情世故指南](https://github.com/changxueyi/renqing-shigu) — 社交与处世经验。
- [沟通的目的](https://openstax.org/books/college-success/pages/8-2-purpose-of-communication) — OpenStax 教材章节，帮助在开口前明确自己希望传达什么、对方需要知道什么（英文）。
- [沟通的情境](https://openstax.org/books/college-success/pages/8-4-the-context-of-communication) — OpenStax 教材章节，讨论场合、受众和沟通渠道如何影响信息传递（英文）。

## 职场发展
- [高性价比职场指南](https://github.com/goodseafly/how-to-make-work-pay) — 职场经验与工作决策。
- [程序员找工作黑名单](https://github.com/shengxinjing/programmer-job-blacklist) — 求职风险参考，具体信息需独立核实。
- [简明写作指南](https://digital.gov/guides/plain-language) — 美国 Digital.gov 的写作手册，介绍如何按读者需求组织内容、改善文档可读性（英文）。
- [开源软件指南](https://opensource.guide/zh-hans/) — 面向开源参与者和维护者的中文手册，从提交第一次贡献到管理项目和社区。

## 安全与防骗
- [人间防骗指南](https://github.com/QERSSD/HowToAvoidScams) — 常见骗局与风险识别。
- [Security in a Box 数字安全指南](https://securityinabox.org/zh/) — Front Line Defenders 项目的中文数字安全手册。
- [电子前哨基金会数字安全自卫指南](https://ssd.eff.org/zh-hans) — 按使用场景查找账号、设备和通信隐私的操作指南，部分条目为英文。
- [FTC 防诈骗指南](https://consumer.ftc.gov/scams) — 按冒充身份、网购、招聘等场景查找骗局识别材料，举报渠道适用于美国（英文）。
- [家庭应急物资清单](https://www.redcross.org/get-help/how-to-prepare-for-emergencies/survival-kit-supplies.html) — 美国红十字会的备灾清单，适合盘点饮水、照明和重要文件等家庭应急用品（英文）。

## 健康与长寿

- [压力之下，择要事为之](https://iris.who.int/bitstream/handle/10665/331901/9789240003910-chi.pdf) — 世界卫生组织的中文图解压力管理手册，附可自行练习的方法。
- [身体活动和久坐行为指南](https://www.who.int/publications/i/item/9789240015128) — 世界卫生组织按年龄和人群编写的公共卫生指南（英文）。

## 日常生活

## 金融与投资
- [投资者教育](https://www.investor.gov/) — 美国证券交易委员会投资者教育资源（英文）。
- [Your Money, Your Goals](https://www.consumerfinance.gov/consumer-tools/educator-tools/your-money-your-goals/toolkit/) — 美国消费者金融保护局的预算、账单与债务工作表，征信和金融规则部分适用于美国（英文）。
- [上交所投资者教育](https://edu.sse.com.cn/) — 面向中国大陆投资者的证券产品、交易制度与风险教育资料。
